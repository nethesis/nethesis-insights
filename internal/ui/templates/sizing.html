Latest day per node

Verdict covers the last 28 days, not this one day. Main cause is whichever resource was worst on most of the bad days. Balance compares the nodes in a cluster: a wide spread means move work between them rather than buy hardware.

What each node runs

Installed modules and their workload counts, on that node's most recent day. Facts counts the instances that answered; a module whose count failed is treated as unknown, not as empty.

Thresholds

The limits the pressure score uses. Basis says where each number comes from — most are still guesses awaiting fleet data, so do not read them as advice.
