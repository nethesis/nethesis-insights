Baselines

What "normal" log volume looks like for one system/module/priority bucket, used by the gate only when a bundle doesn't say how many lines it expected for that bucket. EWMA rate (Exponentially Weighted Moving Average) is a running estimate that leans mostly on history and shifts only a little toward each new window's count — not a hard threshold, just this bucket's baseline rate. The gate compares the actual count against this rate and fires if it's far enough above it (see GATE_TOLERANCE). Rows with module (host) are journal lines (sshd, systemd, …) that carry no module of their own.
