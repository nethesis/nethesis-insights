Gate

Analyses grouped by their exact set of gate reasons, fleet-wide — shows why each window cost money. Each reason is a trigger: the gate calls the AI only if at least one reason fired. Rows with reasons went to the AI; the (none) row is windows gated out for free. A window can have several reasons at once, and each combination is its own row. Watch the gated out share above — that is the gate doing its job.

Reasons are stored as text, exactly as the gate formula wrote them at the time. Older rows can use old wording (e.g. security_category) or embed numbers (e.g. new_templates=5), so an all-time view mixes formats from different versions of the gate.
