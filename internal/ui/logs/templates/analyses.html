Analyses

One row per 15-minute bundle window processed for a system — the cost ledger: why each window did or did not spend money. Gated means the gate decided nothing was new or unusual enough to bother the AI; LLM shows whether it was actually called (skipped windows are gated-out ones handled for free). A window with a suppressed value was not cheap — it was refused by a spend limit, and carries no gate reasons because no gate decision was acted on. Cached is the part of the input the model provider served from its prompt cache, at half price. Hover a truncated cell (gate reasons, error) for the full text.
